# Privacy Policy

Last updated: 2026-02-26

Markdown Browser is designed to minimize data collection.

## Data we collect

- We do not collect personal data.
- We do not run analytics or telemetry.
- We do not sell user data.

## Data stored locally

The extension stores only configuration needed for functionality, such as:

- Link checks setting (enabled/disabled)
- Runtime mode state used for extension behavior consistency

This data is stored in browser extension storage on your device.

## Network behavior

Markdown Browser may perform the following network actions:

- Top-level page requests include markdown preference headers for supported browsing behavior.
- If Link checks is enabled by the user, the extension may send lightweight background checks (HEAD/GET) for links shown on the current markdown page.

Link checks are disabled by default for privacy.

## Data sharing

- No data is shared with third-party analytics providers.
- No data is sold to advertisers or data brokers.

## Security

Markdown Browser includes security controls such as HTML sanitization and constrained extension policies to reduce risk.

## Your choices

- You can keep Link checks disabled for minimal background requests.
- You can remove the extension at any time.
- You can clear extension storage using browser extension management controls.
