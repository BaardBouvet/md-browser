# Support

Last updated: 2026-02-26

Need help with Markdown Browser? Use the information below.

## Contact

- Email: baard.johansen@bouvet.no

## Report an issue

When reporting a problem, include:

- Browser version (Edge/Chrome + version)
- Extension version
- URL where the issue occurs
- Steps to reproduce
- Expected vs actual behavior

## Known limitations

- Best experience is on sites that support markdown negotiation.
- Link capability checks are optional and disabled by default for privacy.
- Some pages may not be suitable for reader mode due to site structure.

## Security and privacy

- Privacy policy: see `PRIVACY.md`
- No analytics/telemetry built into the extension.
