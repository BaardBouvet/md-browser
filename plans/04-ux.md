# Plan: UX

## Principles

- Content-first reading surface.
- Toolbar-first controls (minimal in-page chrome).
- Clear page state feedback via badge/title.

## Current UX baseline

- Reader view replaces noisy page presentation with markdown-oriented styling.
- TOC is available on desktop and hidden on mobile.
- Link capability hints are visible with tooltip details.
- Raw markdown mode is available from the reader interface.

## Interaction model

- Toolbar action toggles page mode.
- Badge communicates high-level state (`M`, `MD`, fallback/help states).
- Reader actions stay lightweight and reversible.

## Known UX pain points

- Some pages still produce imperfect extraction/conversion.
- Tooltip behavior may vary slightly by browser environment.
- State transitions can still feel abrupt on certain sites.

## Next UX steps

- Stabilize edge-case layout/content rendering.
- Tighten state messaging for non-markdown pages.
- Keep UI minimal while improving discoverability of raw mode and link status.
