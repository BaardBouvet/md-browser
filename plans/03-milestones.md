# Plan: Milestones

## Status summary

Core MVP is implemented and running across Chromium/Edge and Firefox builds.

## Phase 1 (completed): MVP foundation

- Build system and manifests for multi-browser targets.
- Request negotiation and markdown detection.
- Reader rendering with fallback conversion path.
- Toolbar and badge status behavior.

## Phase 2 (completed): UX baseline

- In-page reader styling and content layout.
- TOC behavior tuned for desktop/mobile.
- Raw markdown mode with quick toggle.
- Link capability indicators and tooltips.

## Phase 3 (next): hardening and reliability

- Implement prioritized security fixes from gap analysis.
- Tighten permissions and request scope.
- Improve handling of difficult/edge-case pages.
- Add test checklist for release confidence.

## Phase 4 (next): packaging and release readiness

- Finalize store metadata and screenshots.
- Validate install/upgrade behavior per browser.
- Publish candidate builds for broader testing.

## Exit criteria for public beta

- No critical/high unresolved security gaps.
- Stable behavior on target browser set.
- Clear user docs aligned with shipped behavior.
